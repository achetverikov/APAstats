# Get the means between the points of a sequence

Get the means between the points of a sequence

## Usage

``` r
seq_mean(x)
```

## Arguments

- x:

  a vector of numeric values

## Value

means between consecutive values

## Examples

``` r

seq_mean(c(1, 3, 5, 7, 10))
#> [1] 2.0 4.0 6.0 8.5
```
