# Exponentiate scale

Helps to transform log-scale back to normal

## Usage

``` r
scale_y_exp(digits = 0, ...)
```

## Arguments

- digits:

  number of digits to use in labels

- ...:

  other arguments passed to scale_y_continuous

## Value

A continuous y-position scale (class `ScaleContinuousPosition`) with
breaks and labels transformed from logarithmic to exponentiated values.
